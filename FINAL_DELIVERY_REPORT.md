## 2. Completed Deliverables Inside `KAREN_NEXT_FINAL_SOURCE.zip`
1. **Persistent Recovery Journal PIN Transaction Engine (`PinTransactionJournal`):**
   - Implemented an 8-step write-ahead transaction journal stored in encrypted secure storage (`karen_sec_pin_journal_v2_2`) for PIN activation, rotation, and deactivation.
   - Automatic Fail-Closed startup recovery in `LocalStorageService.loadAll()` reconciles interrupted uncommitted or committed journals after crashes/restarts while honoring `rollbackFailed = true` so failed rollbacks never auto-unlock.
   - Fixed a latent bug discovered in `v2_1_2_hardened` where first-time activation wrote `pinLockEnabled: true` into in-flight `PinSecurityState`, causing a mismatch with restart expectations after failed rollback.
2. **Complete Feature & UI/UX Polish:**
   - **Schedules:** Added full **Edit TimeSlot** flow, weekly overview card, Iranian working-day presets, multi-slot daily routines, and responsive `maxWidth: 680` layout.

   - **Reports:** Added manual/phone **Clock Sync** selector sheet, last synced clock display, `کاربران` filter chip, and confirmation-guarded history clearing.
   - **Home & Security UI:** Added responsive layout, quick multi-device switcher chips, recent activity preview (last 3 entries), `PinLockScreen` keystore retry button before destructive wipe, and Persian digits in the PBKDF2 benchmark dialog.

1. Run `./scripts/bootstrap_android_wrapper.sh` (or `.ps1`) on a workstation with Gradle or internet access to generate the official Gradle 9.3.1 wrapper.
2. Run `flutter pub get && flutter analyze && flutter test --coverage && flutter build apk --debug`.
3. Optionally run `./scripts/fetch_vazirmatn_offline.sh` (or `.ps1`) to bundle Vazirmatn `.ttf` binaries offline alongside the already-bundled SIL-OFL `NotoSansArabic` fallback fonts.
4. Benchmark PBKDF2-HMAC-SHA256 (`100,000` vs `600,000` iterations) on target Android hardware using Settings → «آزمون سرعت رمزنگاری (PBKDF2)».
5. Obtain the official Karen Electronic SMS command protocol sheet (or live SMS captures from `karen_1.0.0.apk`) before enabling real hardware SMS control, and configure `android/key.properties` with your release keystore before building signed release APK/AAB artifacts.
